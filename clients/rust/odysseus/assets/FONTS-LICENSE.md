# Bundled fonts

Both are vendored (rather than loaded from the system) so the GUI renders in its
intended typefaces on any machine, and both are under the **SIL Open Font
License 1.1**.

- **Inter** (`Inter-Regular/Medium/SemiBold.ttf`) — Rasmus Andersson.
  https://github.com/rsms/inter — used for UI chrome and chat/body text.
- **Fira Code** (`FiraCode.ttf`) — Nikita Prokopov et al.
  https://github.com/tonsky/FiraCode — used for code, commands, and machine data.
